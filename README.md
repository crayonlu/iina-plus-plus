# IINA++

IINA++ 是 [IINA+](https://github.com/xjbeta/iina-plus) 的 plus 版本，又增加了一些个人觉得提升 UE 的 feature

### 1. 斗鱼回放（直播录像）

### 2. 回放缓存（离线保存）

### 3. 回放弹幕

## 构建

与上游一致：

```bash
bash InstallDeps.sh
open IINA+.xcodeproj
```

下载、使用说明、支持列表与致谢见上游 [IINA+](https://github.com/xjbeta/iina-plus) 的 README 与 Wiki。
